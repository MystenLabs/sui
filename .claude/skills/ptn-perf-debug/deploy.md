# Private testnet (PTN) topology and deployment

Source of truth is `MystenLabs/sui-operations`. Paths below are relative to that repo. Re-verify before relying on
counts or flags; they drift.

## Topology

- Inventory: `ansible/inventory/private-testnet.yaml`. Groups: `ptn3-validators` (~128 hosts), `fullnodes`
  (`lax-ptn3-rpc-00/01`), `ptn-observer-fullnodes`, `ptn-ssfns`, `ptn-stress` (~40 hosts across lax/ash/ams).
- Host naming `{region}-ptn3-{val|rpc|ssfn|obs|stress}-NN`, DNS `{host}.private-testnet.sui.io`, user `ubuntu`.
- Hardware: OpenMetal bare metal (validators ~24C/48T, 256 GB, NVMe; stress hosts smaller). Regions differ in RTT,
  so per-region outliers may be geography, not hardware.
- Node binary `/opt/sui/bin/sui-node`, config `/opt/sui/config/sui-node.yaml`, DBs under `/opt/sui/db/`, systemd
  unit `sui-node.service`. Unit template: `ansible/playbook/sui/roles/sui-node-internal/templates/sui-node.service.j2`
  (env: `RUST_LOG`, `TRACE_FILTER`, `SAMPLE_RATE`, jemalloc heap profiling to `/opt/sui/jeprof/`, tokio-console on
  :6669, `SUI_DB_SYNC_TO_DISK=true`).
- Validator config generated by `scripts/config/generate/generate.py` from `templates/private-testnet.yaml` plus
  `overlays/common.yaml` and `overlays/private-testnet.yaml` (ports, pruning, traffic-control thresholds).
  Fullnodes use `.../templates/fullnode-private-testnet.yaml.j2`.
- Stress: `/opt/sui/bin/stress bench ...`, unit `stress.service`, template
  `ansible/playbook/sui/roles/stress/templates/stress.service.j2`, flags in the `ptn-stress` vars block of the
  inventory. Default ~150 target QPS per host (`ceil(target_tps/40)` when `target_tps` is given), shared-counter +
  transfer-object workloads, 24 workers, driving a fullnode RPC (`lax-ptn3-rpc-01`). Aggregate ~6k TPS.
  If the stress fleet cannot generate the load, nothing downstream can show a bottleneck.

## Observability

- Grafana `https://metrics.sui.io`; PTN metrics in Mimir datasource `mysten-metrics-internal`; logs in Loki tenant
  `private-testnet`. Labels: `host`, `network="private-testnet"`, `role=validator|rpc|ssfn|stress`. Stress client
  metrics are the `localhost_8081` job (`workload` label). node-exporter is scraped on :9091.
- Logs on host: `journalctl -u sui-node` / `journalctl -u stress`. Loki label is `host`, not `hostname`.
- Dashboards under `dashboards/dashboards/f/SDYKsQS4k/suidb/` (Sui Validators, Sui Benchmark, State-Sync).
- PromQL/LogQL cookbook and verified metric names: `.claude/skills/_reference/infrastructure/grafana-datasources.md`.
  Domain notes on stress contention and backpressure: `.claude/skills/_reference/sui-domain-knowledge.md`.
- Regression thresholds the continuous check enforces: `.github/config/private-testnet-performance-checks.yaml`
  (useful as "what does healthy look like").

## Host access

- Teleport: `tsh login --proxy=mysten.teleport.sh --auth=okta`, then `tsh ssh ubuntu@<host>.private-testnet.sui.io`.
- Fleet helper: `bin/ml-env-cli private-testnet check|nodes|ssh "<cmd>" --filter <pattern>|logs|ssh <host>`
  (`python/apps/ml-env-cli/README.md`). Ansible ad-hoc from `ansible/` also works (`ansible/README.md`).

## Workflows (run with `gh workflow run <file> -R MystenLabs/sui-operations ...`)

`sui_commit` must be a full 40-char SHA reachable in `MystenLabs/sui`: push your branch first. Binaries are built
and cached to S3 by `ensure-sui-binaries.yml`; the first deploy of a new SHA takes a build's worth of time.

| workflow | use it for | key inputs |
|---|---|---|
| `sui-node-update.yaml` | **Partial or full node update.** Stop, fetch binary at SHA, optionally wipe db, start. No config regen. Also the way to restart nodes (rerun with the deployed SHA). | `sui_commit`, `environment=private-testnet`, `limit` (ansible pattern: `lax-ptn3-val-00,lax-ptn3-val-01`, `ptn3-validators`, `fullnodes`), `serial` (10/25/50/100%), `reset_db`, `cache_family` |
| `stress-node-update.yaml` | Update stress binary and/or change total load. | `sui_commit`, `environment=private-testnet`, `limit` (default `ptn-stress`), `target_tps` |
| `pulumi-sui-deploy.yaml` | **Full wipe + genesis redeploy** of everything. Needed when the change touches genesis/config generation. | `sui_commit`, `environment=private-testnet`, `protocol_config_override`, `target_tps`, `lock_private_testnet` |
| `environment-lock-unlock.yml` | Lock PTN so the nightly continuous deploy (03:00 UTC Mon-Fri) does not wipe your experiment. Unlock when done. | `environment=private-testnet`, `action=lock\|unlock` |
| `network-throttling.yaml` | Inject bandwidth limits with `tc` on consensus (8081 TCP) or state sync (8084 UDP) for selected hosts. Useful to test a network theory. | `environment`, `limit`, `port`, `ingress_bandwidth`, `egress_bandwidth`, `cleanup` |
| `private-testnet-perf-regression-check.yml` | Runs the metric checker; a quick pass/fail on the last 4h. | none |

Examples:
```
gh workflow run sui-node-update.yaml -R MystenLabs/sui-operations -f sui_commit=<sha> \
  -f environment=private-testnet -f limit=lax-ptn3-val-00,lax-ptn3-val-01 -f serial=100% -f reset_db=false
gh workflow run stress-node-update.yaml -R MystenLabs/sui-operations -f sui_commit=<sha> \
  -f environment=private-testnet -f target_tps=8000
gh workflow run environment-lock-unlock.yml -R MystenLabs/sui-operations -f environment=private-testnet -f action=lock
```

Watch progress with `gh run list -R MystenLabs/sui-operations -w <file>` and `gh run watch <id>`.

## Choosing how many hosts to update

- CPU/storage/local-path changes: 2 to 4 validators (pick the outlier plus a healthy peer) or one fullnode. Compare
  the updated hosts against the rest via the `host` label.
- Network/protocol-adjacent behavior (framing, connection handling, batching): both ends must run the change, so
  update a region or the whole validator set. Roll with `serial=25%` or lower so quorum is never lost.
- Stress-side theories: update a subset of `ptn-stress` and compare per-host stress metrics.
- Never change the protocol or protocol config in an experiment. Anything gated by protocol version needs a full
  wipe deploy and invalidates comparison with the untouched hosts.
