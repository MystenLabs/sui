Stablecoins are fungible tokens designed to maintain a stable value relative to a fiat currency (typically USD). On Sui, stablecoins are standard `Coin<T>` types that you integrate into your app the same way you integrate any other coin. You can accept them as payment, display balances, and transfer them using [programmable transaction blocks](/develop/transactions/ptbs/prog-txn-blocks).

## Integration patterns

You integrate stablecoins the same way you integrate any `Coin<T>` type on Sui. The key patterns are:

- **Accept as payment:** Take a `Coin<USDC>` (or other stablecoin type) as a function parameter and process it like any other coin. See [Creating a Coin](/onchain-finance/fungible-tokens/create-a-fungible-token-coin) for the coin standard reference.
- **Transfer between addresses:** Use `sui::transfer::public_transfer` or [address balances](/onchain-finance/asset-custody/address-balances) to send stablecoins.
- **Gasless transfers:** Eligible stablecoin transfers can use [gasless stablecoin transfers](/develop/transaction-payment/gasless-stablecoin-transfers) to remove gas costs entirely.
- **On/off ramp:** Convert between fiat and stablecoins using [fiat on-ramps](/onchain-finance/asset-custody/fiat-on-ramps) and [fiat off-ramps](/onchain-finance/asset-custody/fiat-off-ramps).

## Decimals and precision

Most stablecoins on Sui use 6 decimals (following the USDC standard). This means 1 USDC is represented as `1_000_000` base units. Always check the `CoinMetadata` for a stablecoin's decimal count before performing arithmetic or displaying balances to users.

## Regulated tokens

Some stablecoins on Sui are [regulated tokens](/onchain-finance/fungible-tokens/regulated-tokens) that support address deny-listing through `DenyCapV2`. This means the issuer can block specific addresses from holding or transacting with the token. Check whether the stablecoin you integrate uses the regulated token standard and account for this in your error handling.
