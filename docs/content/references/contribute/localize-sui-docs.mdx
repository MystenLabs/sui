The Sui documentation can be localized (translated) into any language. The localization platform is [Crowdin](https://support.crowdin.com/crowdin-intro/), which synchronizes the English source files with translation projects where contributors translate strings through an in-browser editor.

## How localization works

The Sui documentation source files are written in English and stored in the [MystenLabs/sui](https://github.com/MystenLabs/sui) repository under `docs/content/`. Crowdin pulls the English source, presents each string for translation, and merges completed translations back into the documentation build. Translated pages appear on docs.sui.io when the user selects a language from the language selector in the site header.

## Getting started

To contribute translations:

1. Visit the [Sui documentation Crowdin project](https://crowdin.com/project/sui-docs) and create a free Crowdin account (or sign in with GitHub or Google).
2. Select the language you want to translate into from the project dashboard.
3. Choose a source file and begin translating using the Crowdin editor. The editor displays the English source on the left and your translation on the right.
4. Submit your translations for review. A reviewer approves or requests changes before the translation is published.

## Translation guidelines

When translating Sui documentation, follow these practices:

- **Do not translate code, CLI commands, or inline code.** Leave all content inside backticks exactly as written. Code must match what the compiler, CLI, or runtime expects.
- **Do not translate product names.** Keep Sui, SUI, Mainnet, Testnet, Devnet, Localnet, Walrus, SuiNS, DeepBook, and other product names in English.
- **Use Crowdin's translation memory.** Crowdin suggests previous translations for similar strings. Use these suggestions to maintain consistency across the documentation.
- **Use the glossary.** Crowdin maintains a glossary of approved term translations. Check the glossary before translating technical terms to ensure consistency.

## Becoming a reviewer

Reviewers approve translations before they appear on the live site. To become a reviewer for a language, contact the Sui documentation team on [Discord](https://discord.gg/sui) with your Crowdin username and target language.
