Enum and scalar type definitions specify the valid values for fields in gRPC [message definitions](fullnode-protocol-messages). Enums define a fixed set of named values (for example, transaction execution status). Scalar types define primitive value formats (for example, byte arrays, integers). Use this reference to interpret field values in gRPC responses and construct valid field values in requests.
