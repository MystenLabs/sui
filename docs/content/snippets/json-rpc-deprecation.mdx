**JSON-RPC is disabled on Sui Foundation Mainnet full nodes.** The shutoff took effect the week of July 27, 2026. Sui Foundation plans full decommission, including code removal, for mid-October 2026. If your application still calls JSON-RPC, migrate to [gRPC](/develop/accessing-data/grpc) or [GraphQL RPC](/develop/accessing-data/graphql/graphql-rpc) now. For a method mapping, decision criteria, and the remaining timeline, see the [JSON-RPC Migration Guide](/develop/accessing-data/json-rpc-migration).

See [RPC and Data Providers](/develop/accessing-data/rpc-providers) for providers that serve gRPC and GraphQL RPC endpoints. Contact a provider directly to request access. If your provider does not yet support these interfaces, ask them to enable support, or reach the Sui Foundation team on Discord, Telegram, or Slack for help.
