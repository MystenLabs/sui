Use the SuiNS SDK to interact with the Sui Name Service. Query SuiNS data in a usable way and build transactions that interact with service names.

## Installation

The SDK declares the [Sui TypeScript SDK](https://sdk.mystenlabs.com/typescript) (`@mysten/sui`) as a peer dependency, so install both:

```bash npm2yarn
$ npm i @mysten/suins @mysten/sui
```

## `SuinsClient`

`SuinsClient` is the base for all SuiNS functionality.

:::info

You should keep only 1 instance of `SuinsClient` throughout your app, API, or script. For example, in React, you should use a context to provide the client.

:::

## Initialize a `SuinsClient`

:::caution

Always keep the dependency updated so you get the latest constants. If you do not, some of your transactions might fail to build.

:::

You can initialize a `SuinsClient` by either providing the active network (`mainnet` or `testnet`),
or by passing in the constants (usable for any network).

<Tabs groupId='initializer'>

<TabItem label="Network initializer" value='network'>
```js
import { SuinsClient } from '@mysten/suins';
import { SuiGrpcClient } from '@mysten/sui/grpc';

// You need a Sui client. You can re-use the Sui client of your project
// (it's not recommended to create a new one).
const client = new SuiGrpcClient({
	network: 'testnet',
	baseUrl: 'https://fullnode.testnet.sui.io:443',
});

// Now you can use it to create a SuiNS client.
const suinsClient = new SuinsClient({
	client,
	network: 'testnet',
});
```
</TabItem>

<TabItem label="Constants initializer" value='constants'>
```js
import { SuinsClient, mainPackage } from '@mysten/suins';
import { SuiGrpcClient } from '@mysten/sui/grpc';

// You need a Sui client. You can re-use the Sui client of your project
// (it's not recommended to create a new one).
const client = new SuiGrpcClient({
	network: 'mainnet',
	baseUrl: 'https://fullnode.mainnet.sui.io:443',
});

// Now you can use it to create a SuiNS client. The SDK exports its package
// constants for Mainnet and Testnet as `mainPackage`. Pass your own
// `PackageInfo` object instead to target a custom deployment.
const suinsClient = new SuinsClient({
	client,
	network: 'mainnet',
	packageInfo: mainPackage.mainnet,
});
```
</TabItem>

</Tabs>

You can also register SuiNS as a client extension. Calling `client.$extend(suins())` returns a client that exposes the same functionality as `SuinsClient` under `client.suins`.
