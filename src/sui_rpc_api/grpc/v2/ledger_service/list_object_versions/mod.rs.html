50/// Serve `ListObjectVersions` from this node's object store, within its retention window. Every
51/// listing is bounded by a checkpoint the rpc indexes have committed: `end_checkpoint - 1`, or the
52/// highest indexed checkpoint when `end_checkpoint` is unset or above it (see
53/// [`ObjectVersionsQuery::checkpoint_window`]). The object's versions at the end of that
54/// checkpoint and of the one before `start_checkpoint`, the request's version range, and its
55/// cursors fold into one inclusive version range (see [`ObjectVersionsQuery::plan`]): the
56/// listing covers the history written in the checkpoint range. Its items, live versions and the
57/// tombstones at which the object was deleted or wrapped, are read in chunks of blocking reads
58/// ([`ChunkedScan`]), so a slow client holds neither an iterator nor a blocking thread.
59///
60/// Pruning removes the versions an object replaced, and the tombstones it left, at or before the
61/// end of the pruned floor checkpoint F ([`retention::read_floor`]), keeping its live version at
62/// the end of it. Its oldest retained version is that version, or for an object with none, the
63/// first item after the floor, live or a removal, that the node places there (see
64/// [`retention::first_retained_version_after_removal`]). The lowest `start_checkpoint` the node
65/// accepts is F + 1, since a range starts above the object's version at the end of the
66/// checkpoint before it: a lower `start_checkpoint`, or an `end_checkpoint` at or below F + 1 in
67/// a listing with no lower bound of its own, fails with `BELOW_EARLIEST_AVAILABLE` (see
68/// [`ObjectVersionsQuery::check_checkpoint_floor`]). A listing bounded by a checkpoint below the
69/// object floor reads no version there: when its `after` cursor is at or above the object's
70/// version at the floor, the cursors leave it nothing to list and it is served empty, as
71/// `ListTransactions` serves one, and otherwise it fails the same way. Every
72/// `BELOW_EARLIEST_AVAILABLE` error of this method reports F + 1 as `lowestAvailableCheckpoint`,
73/// the lowest `start_checkpoint` it accepts, while point reads report F, the lowest
74/// `at_checkpoint` they accept. A request whose `after` cursor comes from a server that has
75/// indexed further than this node gets that cursor's `ABOVE_LATEST_AVAILABLE` instead of any of
76/// these refusals, as `ListTransactions` puts that cursor's tip refusal first (see
77/// [`ObjectVersionsQuery::floor_error`]).
78///
79/// Without `start_checkpoint`, a listing covers only the versions the node retains: it starts at
80/// the oldest retained version when its range reaches below it, and lists nothing for an object
81/// the node retains nothing of, so a descending listing that resumes from a `before` cursor below
82/// the oldest retained version gets an empty page that ends normally. A descending listing that
83/// stops at the oldest retained version ends with a cursor at it, and one that pruning cuts short
84/// while it lists ends where it stopped (see [`CutShort`]), unless it ends at its far cursor,
85/// which it hands back. When it retains nothing of the
86/// object, a request whose listing runs to the tip and whose cursors all come from servers that
87/// have indexed further than this node fails with `ABOVE_LATEST_AVAILABLE`, in either order,
88/// until it catches up (see [`ObjectVersionsQuery::check_some_cursor_indexed`]), since the node
89/// cannot tell an object newer than its tip from one it pruned. Items written at or before the
90/// floor checkpoint that pruning has not deleted yet are passed over, since the versions between
91/// them and the oldest retained one may be gone. A listing fails with `BELOW_EARLIEST_AVAILABLE`
92/// instead when the client already holds history right below the versions it lists, which it
93/// would otherwise follow with a gap: below an `after` cursor, in either order, that names an
94/// item, that is a boundary from a listing bounded below the floor, including one pruning passes
95/// while the listing runs (see [`ObjectVersionsQuery::has_held_after_cursor`]), or that is a
96/// boundary above version 0 when the object's version at the floor is above the version after it
97/// (see [`ObjectVersionsQuery::needs_history_retained_from`]), or an item an earlier chunk of an
98/// ascending listing sent. So does a request with an item's or such a passed boundary's `after`
99/// cursor for an object of which the node retains nothing, and a listing from `start_checkpoint`
100/// that pruning overtakes, which covers its checkpoint range whole or fails, as
101/// `ListTransactions` does. Pruning that overtakes any other listing only trims what it lists.
102///
103/// A listing whose removal mask selects `transaction` finds each removal's transaction (see
104/// [`removals::removal_transaction`], and the notice in [`removals`] on the index that would
105/// replace it), and so has the higher floor of the object floor and the last checkpoint whose
106/// transaction data is pruned; above it, a transaction it cannot find is `INTERNAL`. Without
107/// `transaction`, removals are listed without looking for their transactions.
108///
109/// Nodes without rpc indexes answer `UNIMPLEMENTED` (`NOT_SERVED_HERE`); nodes whose indexes have
110/// not committed a checkpoint yet, or are still backfilling history after a restore, answer
111/// `UNAVAILABLE` (`NOT_READY`) (see [`crate::reader::StateReader::at_checkpoint_upper_bound`]).
112pub(super) async fn list_object_versions(
113    service: RpcService,
114    request: ListObjectVersionsRequest,
115) -> Result<ObjectVersionFrames> {
116    let endpoint = service.config.ledger_history().list_object_versions();
117    let query = ObjectVersionsQuery::new(
118        &request,
119        endpoint.default_limit_items,
120        endpoint.max_limit_items,
121    )?;
122    let chunk_metrics = service
123        .list_metrics
124        .as_ref()
125        .map(|metrics| metrics.stream_metrics(METHOD, RESOLUTION));
126    // Planning runs on a blocking thread; dropping the request cancels it.
127    let planning_cancel = CancellationToken::new();
128    let _planning_cancel_guard = planning_cancel.clone().drop_guard();
129    let listing = spawn_list_chunk(chunk_metrics.clone(), {
130        let service = service.clone();
131        let query = query.clone();
132        move |_| Listing::plan(&service.reader, &query, &planning_cancel)
133    })
134    .await
135    .map_err(storage_error)??;
136    // Tests pause here to prune between planning a listing and reading its first chunk.
137    sui_macros::fail_point_async!("list-object-versions-after-plan");
138
139    let (cut_short_tx, cut_short) = tokio::sync::oneshot::channel();
140    let listed = list_items(
141        service,
142        query.clone(),
143        listing.initial_state,
144        endpoint.chunk_max,
145        chunk_metrics,
146        cut_short_tx,
147    );
148    let bounding_checkpoint = listing.bounding_checkpoint;
149    // A listing that ends at its far cursor hands that back, wherever pruning cut it short: the
150    // checks that admitted the cut found its client holding what pruning took.
151    let ends_at_far_cursor = listing.end == QueryEndReason::CursorBound;
152    let end_cursor = {
153        let query = query.clone();
154        let planned = listing.end_cursor;
155        async move {
156            match cut_short.await {
157                Ok(Some(stop)) if !ends_at_far_cursor => stop.cursor(&query, bounding_checkpoint),
158                _ => planned,
159            }
160        }
161    };
162    Ok(query.frames(bounding_checkpoint, listed, listing.end, end_cursor))
163}

165/// What a fullnode listing reads and how it ends, resolved before it lists anything.
166#[derive(Debug)]
167struct Listing {
168    /// The checkpoint that bounds the listing (see
169    /// [`crate::ledger_history::object_versions::CheckpointWindow::bounding_checkpoint`]).
170    bounding_checkpoint: u64,
171    /// The cursor the listing's last frame resumes from, when it ends below its limit.
172    end_cursor: Bytes,
173    /// Where the first chunk starts reading: the retained versions to read, or `None` if none
174    /// are left to list.
175    initial_state: Option<ObjectVersionScanState>,
176    /// How the listing ends once it has read every item it lists below its limit.
177    end: QueryEndReason,
178}
179
180impl Listing {
181    fn plan(
182        reader: &StateReader,
183        query: &ObjectVersionsQuery,
184        cancel: &CancellationToken,
185    ) -> Result<Self> {
186        let upper_bound = reader.at_checkpoint_upper_bound()?;
187        let window = query.checkpoint_window(&upper_bound)?;
188        let checkpoint = window.bounding_checkpoint;
189        // An empty checkpoint range lists nothing, whatever the floor, so it reads no version at
190        // its checkpoints.
191        if window.is_empty() {
192            let plan = query.plan(&window, &upper_bound, None, None)?;
193            return Ok(Self::reading_nothing(query, &plan, checkpoint));
194        }
195        let lists_transactions = query.lists_removal_transactions();
196        let version_at = |checkpoint| {
197            let indexed = reader.get_object_version_at_checkpoint(
198                query.object_id,
199                checkpoint,
200                &upper_bound,
201            )?;
202            stored_version_of_indexed(reader, query.object_id, indexed)
203        };
204        let floors = read_floor(reader, lists_transactions)?;
205        query.check_checkpoint_floor(floors.floor_checkpoint, &upper_bound, version_at)?;
206        if let Some(listing) = Self::bounded_below_object_floor(
207            reader,
208            query,
209            &window,
210            &upper_bound,
211            floors.object_floor,
212            lists_transactions,
213            version_at,
214        )? {
215            return Ok(listing);
216        }
217        let newest_at_tip = version_at(upper_bound.highest_indexed())?;
218        let newest_visible = if checkpoint == upper_bound.highest_indexed() {
219            newest_at_tip
220        } else {
221            version_at(checkpoint)?
222        };
223        let newest_before_start = match window.below_start {
224            Some(below_start) => version_at(below_start)?,
225            None => None,
226        };
227        // Nothing of this object is retained up to the listing's checkpoint. On a node that has
228        // pruned objects, it never existed, or was deleted or wrapped at or before the floor and
229        // pruning dropped its rows, or its history starts above that checkpoint, and the node
230        // cannot tell which. A request whose listing runs to the tip and whose cursors all come
231        // from servers that have indexed further may hold versions this node has not indexed
232        // yet, or ones it pruned, so it fails with `ABOVE_LATEST_AVAILABLE`, in either order,
233        // until this node catches up. A request whose `after` cursor holds history that pruning
234        // may have cut a gap after (see `ObjectVersionsQuery::has_held_after_cursor`) then fails
235        // with the floor error: a removal the node no longer has rows for may follow it. Any
236        // other lists nothing, and a descending one ends as at the object's first version, even
237        // from a `before` cursor the plan would take for one past the tip. The floor is read
238        // after the version: pruning raises it no later than it drops rows.
239        let nothing_retained_floor = match newest_visible {
240            None if reader.at_checkpoint_lower_bound()?.pruned_floor().is_some() => {
241                read_floor(reader, lists_transactions)?.floor_checkpoint
242            }
243            _ => None,
244        };
245        if nothing_retained_floor.is_some() {
246            query.check_some_cursor_indexed(&window, &upper_bound)?;
247        }
248        let plan = match nothing_retained_floor {
249            Some(floor_checkpoint) if query.has_held_after_cursor(Some(floor_checkpoint)) => {
250                return Err(query.floor_error(floor_checkpoint, &upper_bound));
251            }
252            Some(_) if query.descending => query.nothing_retained(),
253            _ => query.plan(&window, &upper_bound, newest_visible, newest_before_start)?,
254        };
255        // After the reads: pruning may have raised the floor past the checkpoints they read at
256        // while they ran (see `StateReader::at_checkpoint_lower_bound`).
257        let floors = read_floor(reader, lists_transactions)?;
258        query.check_checkpoint_floor(floors.floor_checkpoint, &upper_bound, version_at)?;
259        if let Some(listing) = Self::bounded_below_object_floor(
260            reader,
261            query,
262            &window,
263            &upper_bound,
264            floors.object_floor,
265            lists_transactions,
266            version_at,
267        )? {
268            return Ok(listing);
269        }
270        // An object with a version at the listing's checkpoint has one at the tip too.
271        let (Some(versions), Some(newest_version)) = (plan.versions.clone(), newest_at_tip) else {
272            return Ok(Self::reading_nothing(query, &plan, checkpoint));
273        };
274        let tip = IndexedTip {
275            newest_version,
276            upper_bound,
277        };
278        let retention = Retention::read(
279            reader,
280            query.object_id,
281            &tip,
282            floors.floor_checkpoint,
283            lists_transactions,
284            cancel,
285        )?;
286        // The floor `Retention::read` settled on, which pruning may have raised since the check
287        // above, bounds a listing from `start_checkpoint` too.
288        if retention.floor_checkpoint != floors.floor_checkpoint {
289            query.check_checkpoint_floor(retention.floor_checkpoint, &upper_bound, version_at)?;
290        }
291        let start = *versions.start();
292        let client_holds_item_below =
293            query.needs_history_retained_from(start, retention.floor_checkpoint);
294        // A `start_checkpoint` below the lowest one this floor accepts passed
295        // `check_checkpoint_floor` only on its `after` cursor, which leaves the object's history
296        // from `start` unvouched for when the object has no version at the floor: it may have
297        // been removed at or before it, its later versions pruned. Unless the cursor bounds the
298        // listing, which starts right after it, and is a boundary bounded at or above the floor
299        // (see `ObjectVersionsQuery::has_held_after_cursor`; a boundary above version 0 has
300        // already passed `check_checkpoint_floor`'s check of the object's version at the floor),
301        // that history must then be retained, as for a client holding the item right below it.
302        let start_below_floor = retention
303            .lowest_start_checkpoint()
304            .zip(query.start_checkpoint)
305            .is_some_and(|(lowest_start, start_checkpoint)| start_checkpoint < lowest_start);
306        if client_holds_item_below
307            || (start_below_floor
308                && (query.has_held_after_cursor(retention.floor_checkpoint)
309                    || !query.starts_after_cursor(start)))
310        {
311            retention.check_keeps_from(start, query, &upper_bound)?;
312        }
313        let read_from = retention
314            .first_kept_from(start)
315            .filter(|read_from| read_from <= versions.end());
316        // A listing whose range reaches below the oldest retained version starts there, and a
317        // descending one that would end at its window's edge stops there and resumes from it. One
318        // that ends at its far cursor hands that cursor back.
319        let stops_at_oldest = read_from.filter(|&read_from| {
320            query.descending && plan.end != QueryEndReason::CursorBound && read_from > start
321        });
322        Ok(Self {
323            bounding_checkpoint: checkpoint,
324            end_cursor: match stops_at_oldest {
325                Some(oldest) => query.cursor(oldest.value(), checkpoint),
326                None => query.end_cursor(&plan, checkpoint),
327            },
328            initial_state: read_from.map(|read_from| ObjectVersionScanState {
329                versions: read_from..=*versions.end(),
330                retention,
331                tip,
332                previous_removal: None,
333                client_holds_item_below,
334                after_cursor_below: query.starts_after_cursor(start),
335            }),
336            end: plan.end,
337        })
338    }
339
340    /// A listing of `plan`, bounded by `bounding_checkpoint`, that reads nothing.
341    fn reading_nothing(
342        query: &ObjectVersionsQuery,
343        plan: &ObjectVersionsPlan,
344        bounding_checkpoint: u64,
345    ) -> Self {
346        Self {
347            bounding_checkpoint,
348            end_cursor: query.end_cursor(plan, bounding_checkpoint),
349            initial_state: None,
350            end: plan.end,
351        }
352    }
353
354    /// The listing of a request whose window's bounding checkpoint is below `object_floor`, the
355    /// object floor as the caller last read it (see [`retention::Floors`]), or `None` when it is
356    /// at or above it or nothing is pruned. The object's versions at checkpoints below the floor
357    /// may be pruned, so its window is not read, and `check_checkpoint_floor` refuses every such
358    /// request without an `after` cursor. An `after` cursor at or above the object's version at
359    /// the end of the floor checkpoint is at or above every version written by the bounding
360    /// checkpoint, so the cursors leave nothing to list, and the listing is served empty, as
361    /// `ListTransactions` serves a scan its cursors alone leave empty: it is planned as if the
362    /// object's newest version by then were its version at the floor, which the cursor passes.
363    /// Any other request fails with the floor error, since this node cannot tell what its window
364    /// holds.
365    fn bounded_below_object_floor(
366        reader: &StateReader,
367        query: &ObjectVersionsQuery,
368        window: &CheckpointWindow,
369        upper_bound: &AtCheckpointUpperBound,
370        object_floor: Option<u64>,
371        lists_transactions: bool,
372        version_at: impl FnOnce(u64) -> Result<Option<SequenceNumber>>,
373    ) -> Result<Option<Self>> {
374        let Some(object_floor) =
375            object_floor.filter(|&object_floor| window.bounding_checkpoint < object_floor)
376        else {
377            return Ok(None);
378        };
379        let at_floor = version_at(object_floor)?;
380        if !query.after_at_or_above(at_floor) {
381            let floor_checkpoint = read_floor(reader, lists_transactions)?
382                .floor_checkpoint
383                .unwrap_or(object_floor);
384            return Err(query.floor_error(floor_checkpoint, upper_bound));
385        }
386        let plan = query.plan(window, upper_bound, at_floor, None)?;
387        Ok(Some(Self::reading_nothing(
388            query,
389            &plan,
390            window.bounding_checkpoint,
391        )))
392    }
393}

395/// The version in the object store of the item the version index records at `indexed` (see
396/// [`stored_version_at`]).
397pub(super) fn stored_version_of_indexed(
398    reader: &StateReader,
399    object_id: ObjectID,
400    indexed: Option<SequenceNumber>,
401) -> Result<Option<SequenceNumber>> {
402    let Some(indexed) = indexed else {
403        return Ok(None);
404    };
405    let first_stored = reader
406        .object_versions_iter(object_id, indexed..=SequenceNumber::MAX, false)?
407        .next()
408        .transpose()?;
409    Ok(Some(stored_version_at(indexed, first_stored.as_ref())))
410}

412/// The version in the object store of the item the version index records at `indexed`, given
413/// the object's first stored item at or above `indexed`. They differ for a deletion or wrap by a
414/// transaction with V1 effects: the index records `TransactionEffectsAPI::lamport_version`,
415/// which V1 effects recompute from the modified objects alone, while the tombstone sits at the
416/// version the transaction executed at, which also counts its read-only inputs. No item lies
417/// between the two, so when the store holds nothing at `indexed`, a tombstone right above it is
418/// that removal.
419fn stored_version_at(
420    indexed: SequenceNumber,
421    first_stored: Option<&ObjectOrTombstone>,
422) -> SequenceNumber {
423    match first_stored {
424        Some(ObjectOrTombstone::Tombstone((_, version, _))) if *version > indexed => *version,
425        _ => indexed,
426    }
427}

429/// The highest checkpoint the indexes had committed when the listing was planned, and the
430/// object's newest version at the end of it. Every read that places an item by the version
431/// index, or finds the transaction behind a removal, is bounded by them, so it reads only what
432/// the indexes have committed.
433#[derive(Clone, Copy, Debug)]
434struct IndexedTip {
435    newest_version: SequenceNumber,
436    upper_bound: AtCheckpointUpperBound,
437}

439/// How the object was removed at the tombstone whose digest is `digest`.
440pub(super) fn removal_kind(digest: &ObjectDigest) -> Result<ObjectRemovalKind> {
441    if digest.is_deleted() {
442        Ok(ObjectRemovalKind::Deleted)
443    } else if digest.is_wrapped() {
444        Ok(ObjectRemovalKind::Wrapped)
445    } else {
446        Err(storage_error(format!(
447            "tombstone with unexpected digest {digest}"
448        )))
449    }
450}
451
452pub(super) fn stored_version(item: &ObjectOrTombstone) -> SequenceNumber {
453    match item {
454        ObjectOrTombstone::Object(object) => object.version(),
455        ObjectOrTombstone::Tombstone((_, version, _)) => *version,
456    }
457}

459/// One chunk worker's input: the versions left to read, and what bounds them.
460#[derive(Debug)]
461struct ObjectVersionScanState {
462    versions: RangeInclusive<SequenceNumber>,
463    retention: Retention,
464    tip: IndexedTip,
465    /// The removal the listing found last, which the lookup for the next tombstone in listing
466    /// order starts from when the two are next to each other (see [`removal_transaction`]).
467    previous_removal: Option<FoundRemoval>,
468    /// Whether the client holds history right below `versions` that pruning through the floor
469    /// the listing was planned under may have cut a gap after: below the `after` cursor the
470    /// listing starts right after (see [`ObjectVersionsQuery::needs_history_retained_from`]), or
471    /// an item an earlier chunk of an ascending listing sent. Pruning that deletes versions
472    /// between it and `versions` fails the listing, which would otherwise skip them.
473    client_holds_item_below: bool,
474    /// Whether `versions` starts right after the request's `after` cursor, of either kind (see
475    /// [`ObjectVersionsQuery::starts_after_cursor`]): for every chunk of a descending listing,
476    /// and until it sends an item for an ascending one. Pruning that later passes a boundary
477    /// cursor's checkpoint makes its client hold history right below `versions` too.
478    after_cursor_below: bool,
479}

481/// Where a descending listing that pruning cut short while it listed stops, which its last
482/// frame's cursor names in place of the planned one, except when the listing ends with
483/// `CURSOR_BOUND`, whose far cursor stays: the listing sent every version it reached above that
484/// point and none at or below it, so a client resuming from it, on this node or on one that has
485/// pruned less, neither skips nor repeats a version.
486#[derive(Clone, Copy, Debug)]
487enum CutShort {
488    /// The lowest item the listing sent, which the chunk that found the cut sent.
489    Item(SequenceNumber),
490    /// The boundary right above this version, the highest of the versions the chunk that found
491    /// the cut read: that chunk sent nothing, and earlier chunks sent every item above them.
492    Boundary(SequenceNumber),
493}
494
495impl CutShort {
496    /// The cursor of this point, minted by a listing bounded by `bounding_checkpoint`.
497    fn cursor(self, query: &ObjectVersionsQuery, bounding_checkpoint: u64) -> Bytes {
498        match self {
499            Self::Item(version) => query.cursor(version.value(), bounding_checkpoint),
500            Self::Boundary(version) => query.boundary_cursor(version.value(), bounding_checkpoint),
501        }
502    }
503}

505/// The items of the listing whose first chunk reads `initial_state`, rendered, in listing order,
506/// up to the query's limit. Once they end, `cut_short` receives where pruning cut the listing
507/// short, if it did.
508fn list_items(
509    service: RpcService,
510    query: ObjectVersionsQuery,
511    initial_state: Option<ObjectVersionScanState>,
512    chunk_max: usize,
513    chunk_metrics: Option<ListStreamMetrics>,
514    cut_short: tokio::sync::oneshot::Sender<Option<CutShort>>,
515) -> BoxStream<'static, Result<ObjectVersionItem>> {
516    let limit = query.limit;
517    async_stream::try_stream! {
518        if let Some(initial_state) = initial_state {
519            let mut scan = ChunkedScan::new(initial_state, limit, chunk_max, 0, move |state, args| {
520                let service = service.clone();
521                let query = query.clone();
522                spawn_list_chunk(chunk_metrics.clone(), move |_| {
523                    next_object_version_chunk(&service, &query, state, args)
524                })
525            });
526            while let Some(item) = scan.next_item().await? {
527                yield item;
528            }
529            // Sending fails only once the frames, which hold the receiver, are dropped.
530            let _ = cut_short.send(scan.into_terminal().flatten());
531        }
532    }
533    .boxed()
534}

536/// A chunk's result. Its terminal is where pruning cut a descending listing short, set by the
537/// chunk that found the cut, which is the listing's last.
538type ObjectVersionChunkDone =
539    ScanChunkDone<ObjectVersionScanState, ObjectVersionItem, Option<CutShort>>;
540
541/// Read and render up to `args.chunk_item_limit` items from `state.versions` in listing order,
542/// finding the transaction behind each removal when the query lists them, then check the
543/// retention floor against everything the chunk read, the items and the removal lookups alike.
544/// Pruning that has raised the object's oldest retained version above the versions read fails
545/// the listing if the client holds history right below them (see
546/// [`ObjectVersionScanState::client_holds_item_below`] and
547/// [`ObjectVersionScanState::after_cursor_below`]) or the listing is from `start_checkpoint`, and
548/// otherwise leaves only the items at or above it: a descending listing reads no further and ends
549/// where it stopped (see [`CutShort`]), and an ascending one goes on.
550/// A lookup can miss a removal the floor still keeps when it walked from a removal pruning has
551/// since taken, or through rows pruning deleted; when the floor moved, the chunk lists nothing
552/// and leaves the same versions for the next chunk to read under the new floor. Fails with
553/// `CANCELLED` once the chunk is cancelled, and with `INTERNAL` for a retained removal whose
554/// transaction cannot be found under a floor that held still.
555fn next_object_version_chunk(
556    service: &RpcService,
557    query: &ObjectVersionsQuery,
558    state: ObjectVersionScanState,
559    args: ChunkArgs,
560) -> Result<ObjectVersionChunkDone> {
561    let reader = &service.reader;
562    let limit = args.chunk_item_limit;
563    let cancel = &args.cancel;
564    let render_context = RenderContext::empty(reader.inner());
565    if cancel.is_cancelled() {
566        return Err(cancelled());
567    }
568    let ObjectVersionScanState {
569        versions,
570        retention,
571        tip,
572        mut previous_removal,
573        client_holds_item_below,
574        after_cursor_below,
575    } = state;
576    let stored = reader
577        .object_versions_iter(query.object_id, versions.clone(), query.descending)?
578        .take(limit)
579        .collect::<Result<Vec<_>>>()?;
580
581    // A full chunk may leave versions past its last one; a short one read the whole range.
582    let last_read = stored
583        .last()
584        .filter(|_| stored.len() == limit)
585        .map(stored_version);
586    let lowest_read = match last_read {
587        Some(last) if query.descending => last,
588        _ => *versions.start(),
589    };
590
591    let mut items = Vec::with_capacity(stored.len());
592    for item in stored {
593        if cancel.is_cancelled() {
594            return Err(cancelled());
595        }
596        let item = match item {
597            ObjectOrTombstone::Object(object) => ObjectVersionItem::Live {
598                object: service.render_object_to_proto(&object, &query.read_mask, &render_context),
599                version: object.version(),
600            },
601            ObjectOrTombstone::Tombstone((_, version, digest)) => {
602                let kind = removal_kind(&digest)?;
603                let transaction = if query.lists_removal_transactions() {
604                    // Tests pause here to prune between two removal lookups of one chunk.
605                    sui_macros::fail_point!("list-object-versions-before-removal-lookup");
606                    previous_removal = removal_transaction(
607                        reader,
608                        query.object_id,
609                        version,
610                        previous_removal,
611                        retention.floor_checkpoint,
612                        &tip,
613                        cancel,
614                    )?
615                    .map(|transaction| FoundRemoval {
616                        version,
617                        transaction,
618                    });
619                    previous_removal.map(|found| found.transaction.digest)
620                } else {
621                    None
622                };
623                ObjectVersionItem::Removal {
624                    version,
625                    kind,
626                    transaction,
627                }
628            }
629        };
630        items.push(item);
631    }
632
633    // The floor, read after every read of the chunk: pruning raises it no later than it deletes
634    // versions or the transactions behind them, so whatever this read keeps was read whole,
635    // unless a lookup missed.
636    let reread = retention.reread(reader, query.object_id, &tip, cancel)?;
637    // With transactions listed, a removal without one is a lookup that missed.
638    let missing = items.iter().find_map(|item| match item {
639        ObjectVersionItem::Removal {
640            version,
641            transaction: None,
642            ..
643        } if query.lists_removal_transactions() && reread.keeps_from(*version) => Some(*version),
644        _ => None,
645    });
646    if let Some(missing) = missing {
647        // Checkpoint pruning deletes effects before it raises the floor `read_floor` reads, so a
648        // prune racing a lookup can still end the listing here.
649        if reread.floor_checkpoint == retention.floor_checkpoint {
650            return Err(RpcError::new(
651                tonic::Code::Internal,
652                format!(
653                    "missing the transaction that removed object {} at version {}, above the \
654                     retention floor",
655                    query.object_id,
656                    missing.value()
657                ),
658            ));
659        }
660        return Ok(ScanChunkDone {
661            produced: 0,
662            next_state: Some(ObjectVersionScanState {
663                versions,
664                retention: reread,
665                tip,
666                previous_removal: None,
667                client_holds_item_below,
668                after_cursor_below,
669            }),
670            items: Vec::new(),
671            terminal: None,
672            remaining_scan_budget: args.scan_budget,
673        });
674    }
675    let retention = reread;
676    // Set when pruning has raised the oldest retained version above versions this chunk read,
677    // which ends a descending listing.
678    let overtaken = !retention.keeps_from(lowest_read);
679    if overtaken {
680        // A boundary `after` cursor that pruning has passed since the listing was planned now
681        // leaves a gap below `versions` too.
682        let client_holds_history_below = client_holds_item_below
683            || (after_cursor_below && query.has_held_after_cursor(retention.floor_checkpoint));
684        if client_holds_history_below || query.start_checkpoint.is_some() {
685            retention.check_keeps_from(lowest_read, query, &tip.upper_bound)?;
686        }
687        items.retain(|item| retention.keeps_from(item.version()));
688    }
689    let produced = items.len();
690    let cut_short = (overtaken && query.descending).then(|| match items.last() {
691        Some(lowest_sent) => CutShort::Item(lowest_sent.version()),
692        None => CutShort::Boundary(*versions.end()),
693    });
694
695    // A descending listing that pruning overtook has read every item it keeps. An ascending one
696    // goes on from its last read, above the versions pruning deleted.
697    let remaining = last_read.filter(|_| cut_short.is_none()).and_then(|last| {
698        if query.descending {
699            let below = last.one_before()?;
700            (*versions.start() <= below).then(|| *versions.start()..=below)
701        } else {
702            let above = SequenceNumber::from_u64(last.value().checked_add(1)?);
703            (above <= *versions.end()).then(|| above..=*versions.end())
704        }
705    });
706    Ok(ScanChunkDone {
707        produced,
708        next_state: remaining.map(|versions| ObjectVersionScanState {
709            versions,
710            // A lookup next to a removal the floor no longer keeps could walk through rows
711            // pruning deleted.
712            previous_removal: previous_removal.filter(|found| retention.keeps_from(found.version)),
713            retention,
714            tip,
715            client_holds_item_below: client_holds_item_below || (!query.descending && produced > 0),
716            after_cursor_below: after_cursor_below && (query.descending || produced == 0),
717        }),
718        items,
719        terminal: cut_short,
720        remaining_scan_budget: args.scan_budget,
721    })
722}

731    /// A V1 removal indexed below its tombstone resolves to the tombstone. Anything else at or

735        let id = ObjectID::from_single_byte(7);
736        let version = SequenceNumber::from_u64;
737        let tombstone = |at| {
738            ObjectOrTombstone::Tombstone((id, version(at), ObjectDigest::OBJECT_DIGEST_DELETED))
739        };

741            id,
742            version(6),
743            Owner::Immutable,
744        ));

746        assert_eq!(

748            version(6)
749        );
750        assert_eq!(
751            stored_version_at(version(5), Some(&tombstone(5))),
752            version(5)

755        assert_eq!(stored_version_at(version(5), None), version(5));
