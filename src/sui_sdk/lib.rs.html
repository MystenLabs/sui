4//! Client-side utilities for interacting with a Sui network from Rust.
5//!
6//! The JSON-RPC client this crate used to provide was removed together with
7//! the fullnode JSON-RPC service. What remains is the wallet and configuration
8//! layer shared by the Sui CLI and the tooling in this repository:
9//!
10//! * [`wallet_context::WalletContext`] - the keystore-backed wallet used to
11//!   sign and execute transactions against a network over gRPC.
12//! * [`sui_client_config::SuiClientConfig`] - the persisted client
13//!   configuration (`client.yaml`) and its named network environments.
14//! * [`verify_personal_message_signature`] - verification of personal message
15//!   signatures through a fullnode.
16//!
17//! For a general-purpose Rust SDK, use the
18//! [`sui-rust-sdk`](https://github.com/MystenLabs/sui-rust-sdk) crate.
19
