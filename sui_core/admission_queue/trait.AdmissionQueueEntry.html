fn dedup_keys(&self) -> &[DedupKey] ⓘ

Keys this entry is deduped on, sorted with duplicates removed: two queued entries sharing one can never both execute, so only the highest-priced is admitted. Both lanes supply gas_dedup_keys, the gas payment objects being the only inputs that are unambiguously owned without a state read.

fn byte_size(&self) -> usize

Returns the bytes that the queue counts against its byte capacity. The value must not change while the entry is queued.
