Shared harness for the sui-fork end-to-end tests.

The test targets in this crate all need a source network that a fork can be taken from (a sui start child), the binaries under test, and a way to run a script without leaking its background processes, so those pieces live in this library rather than under tests/. A module under tests/ is compiled once per test target, and each target would then warn about the items the others use.
