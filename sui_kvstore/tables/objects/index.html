sui_kvstore::tables

Module objects 

Source
Expand description

Objects table: every version of every object, plus tombstones at the versions where objects were deleted or wrapped.

Row key: object_id (32B) || version (8B big-endian)

A row holds exactly one of:

  • "": the BCS-encoded [Object] at that version (a live row), or
  • s: a one-byte ObjectStatus, Deleted or Wrapped (a tombstone), marking the version at which the object was removed from the live set.

The newest row at or below version V is the object’s state at V: a live row is the object’s contents, a tombstone means the object did not exist at V. Tombstones are written by a separate pipeline from live rows, so they are only present where that pipeline has run.
