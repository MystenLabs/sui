pub fn protocol_config_from_parts(
    protocol_version: u64,
    attributes: BTreeMap<String, Value>,
    feature_flags: BTreeMap<String, bool>,
) -> ProtocolConfig
Expand description

Builds the proto message from a version’s rendered settings and its feature flags.

attributes is the output of ProtocolConfig::render, with a null value for each setting that has no value at protocol_version. feature_flags is ProtocolConfig::feature_map. Settings with no value are left out of both configs and attributes.
