pub fn pages_by_token(request: &ListPackageVersionsRequest) -> bool
Expand description

Whether request pages by page token, as on servers that predate cursor paging: it names a package with package_id and sets none of the fields that select cursor paging, options, start_version, end_version, start_checkpoint and end_checkpoint, so it has the request shape those servers accept. The listing of every package, with package_id unset, always pages by cursor. Public so other implementors of MovePackageService tell the two paging modes apart the same way.
