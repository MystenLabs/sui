PackageVersionCursor
The position of one listed version, set as PackageVersion.cursor and accepted back as options.after and options.before. Public so other implementors of MovePackageService mint and accept the same cursors. check_checkpoint_range
Check the checkpoint range of a ListPackageVersions request against highest_indexed, the highest checkpoint the server has indexed, before the listing reads anything. Validate the request with validate_request first, and, for a package the server knows, check that its page token or cursors name the package’s lineage with PackageVersionsQuery::new, so a malformed request is refused as such whatever its range. Public so other implementors of MovePackageService refuse the same requests.

pages_by_token
Whether request pages by page token, as on servers that predate cursor paging: it names a package with package_id and sets none of the fields that select cursor paging, options, start_version, end_version, start_checkpoint and end_checkpoint, so it has the request shape those servers accept. The listing of every package, with package_id unset, always pages by cursor. Public so other implementors of MovePackageService tell the two paging modes apart the same way.
unknown_package_response
The answer to a request in cursor mode for a package the server does not know as of highest_indexed, the highest checkpoint it has indexed (kv-rpc: its served height): no version of it was published at or below that checkpoint. Public so other implementors of MovePackageService answer such requests the same way. Check the request’s checkpoint range with check_checkpoint_range first.
validate_request
Validate a ListPackageVersions request before any range, tip or floor rule applies to it, as the other List methods validate theirs, so a malformed request is INVALID_ARGUMENT whatever its range: an end_checkpoint below start_checkpoint, an invalid options.ordering, or a page token or cursor that does not decode, or that the other listing minted (a lineage cursor with package_id unset, or one of the listing of every package with it set). A lineage listing also refuses an end_version below start_version, and page_size or page_token combined with a field that selects cursor paging (see pages_by_token); the listing of every package refuses page_size, page_token, start_version and end_version. Reads nothing, so it runs before the package is loaded; whether a page token or cursor names the requested lineage is checked once the package is loaded, by PackageVersionsQuery::new. Public so other implementors of MovePackageService refuse the same requests.
