CursorToken
Pagination cursor for ledger-history endpoints.
LedgerPoint
A boundary in public ledger order (sui.rpc.v2.LedgerPosition): just before the item keyed (checkpoint, transaction_index, event_index). An index past the last transaction of a checkpoint (or past the last event of a transaction) names the start of the next one, so different points can name the same boundary; they still order correctly against every item key. Transaction cursors carry event_index 0.

CursorKind
Whether a cursor position is a matched row that was returned to the client (Item) or a scan frontier the server reached (Boundary).
Position
Endpoint-specific cursor position. Transaction and event positions carry public_position, the boundary immediately before the item at their coordinate in public ledger coordinates, independent of the cursor’s kind: an item cursor’s item key, or the boundary a boundary cursor names. It only labels the cursor: scans are bounded by tx_seq and event_index alone.
